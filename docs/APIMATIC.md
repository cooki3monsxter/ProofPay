# ProofPay × APIMatic

ProofPay is both a **consumer** and a **producer** of APIs:

- It consumes PayPal's APIs. PayPal's official server SDKs are generated by APIMatic.
- It produces its own API so other apps and agents can offer pay-on-proof escrow. APIMatic turns that
  API's OpenAPI spec into everything an integrator needs.

## Layout APIMatic expects

```
apimatic/
  src/
    spec/
      openapi.yaml   ← the single source of truth
```

## Commands

```bash
npx @apimatic/cli auth login                       # once
npm run apimatic:validate                          # syntactic + semantic validation
npm run apimatic:sdk:java                          # SDK in ./sdks/java
npm run apimatic:sdk:ts                            # SDK in ./sdks/typescript
npm run apimatic:sdk:python                        # SDK in ./sdks/python
npm run apimatic:portal                            # static developer portal
npx @apimatic/cli portal serve --input=./apimatic  # preview portal with live reload
npx @apimatic/cli plugin generate --input=./apimatic  # context plugin for AI coding assistants
```

## MCP server from the spec

In the APIMatic dashboard, import `apimatic/src/spec/openapi.yaml` and use the **MCP Server Generator** to
produce a versioned MCP server. Compare it with the hand-written server in `src/mcp/tools.ts`, which adds
agent-specific guidance (e.g. "give the human the approval link") on top of the raw operations.

## Keeping things in sync

- `tests/proofpay.test.ts` fails if a path in the spec isn't served by the API.
- `.github/workflows/ci.yml` validates the spec and regenerates the TypeScript SDK on every push when
  the repository variable `APIMATIC_ENABLED=true` and the secret `APIMATIC_API_KEY` are set.

## Using a generated SDK (Java example)

The exact class names come from the generator; the shape will look like this. The spec declares bearer
auth, so the generated client takes the escrow key once:

```java
ProofPayClient anon = new ProofPayClient.Builder().environment(Environment.PRODUCTION).build();

CreateFromScopeRequest req = new CreateFromScopeRequest.Builder(
        "Milestone 1: Landing page - $300, due in 7 days. Live at a public URL.",
        new Party("Asha", "asha@example.com"),
        new Party("Dev", "dev@example.com"))
    .build();
var created = anon.getEscrowsController().createEscrowFromScope(req, null);

// Act as the client from here on
ProofPayClient client = anon.newBuilder()
    .bearerAuthCredentials(new BearerAuthModel.Builder(created.getAccess().getClientKey()).build())
    .build();
var fund = client.getMilestonesController()
    .fundMilestone(created.getEscrow().getMilestones().get(0).getId());
System.out.println("Approve the hold: " + fund.getApprovalUrl());
System.out.println("Send to the freelancer: " + created.getAccess().getFreelancerLink());
```
