How to check this yourself, without ProofPay

Each delivery is a standard JWS (RFC 7515) signed with Ed25519. The public key is published at /.well-known/jwks.json. Any JOSE library can verify it, for example in Node:

import { createRemoteJWKSet, jwtVerify } from "jose";
const keys = createRemoteJWKSet(new URL("https://<issuer>/.well-known/jwks.json"));
const { payload } = await jwtVerify(token, keys);   // throws if altered

To confirm whose record this is, ask for their email and compare sha256("proofpay:subject:" + email.toLowerCase()) with the freelancer field — the box above does that for you. Live status (a PayPal dispute or refund after release) is at /api/attestations/<id>/status.
